# mdh 语法介绍

> **面向要写 `.mdh` 的人。** 看完能写出完整的 mdh 文档。
>
> 如果你写过 Markdown，大部分地方你直接就会。

---

## 一、符号总表

| 写法 | 用途 | 例子 |
|---|---|---|
| `#` ~ `######` | 标题 H1–H6 | `# 标题` |
| `**文字**` | 加粗 | `**重要**` |
| `/文字/` | 斜体 | `/斜体/` |
| `__文字__` | 下划线 | `__下划线__` |
| `--文字--` | 删除线 | `--废稿--` |
| `- 项` | 无序列表 | `- 苹果` |
| `1. 项` | 有序列表 | `1. 第一步` |
| `- [ ]` / `- [x]` | 任务项 | `- [x] 完成` |
| `>` | 引用 | `> 引用` |
| `>>` | 二级引用 | `>> 引用里的引用` |
| `` `文字` `` | **行内原样输出**（等宽、不解析） | `` `# 不是标题` `` |
| `$...$` | 行内公式 | `$O(n \log n)$` |
| `---` | 分割线（3–10 个减号） | `---` |
| `//` | 行注释（不渲染） | `// 备注` |
| `===` … `===` | 元信息区块 | 见 [§8](#八元信息) |
| `***块名` … `***块名-end` | 声明式块 | `***table` … `***table-end` |

### 和 Markdown 不一样的地方

| Markdown 写法 | mdh 的写法 | 为什么换 |
|---|---|---|
| `[文字](url)` | `@link(文字, "url")` | `[]()` 里塞不下带逗号的地址 |
| `![alt](url)` | `@img(alt, "url")` | 不用 `!` 去区分图片和链接 |
| `\` 转义 | 反引号包住 | 只有一个转义手段，好记 |

## 二、空白语义：空几行就是空几行

**这是 mdh 最主要的设计：源码怎么写，就怎么显示。**

### 空行

| 你按的回车 | 渲染结果 |
|---|---|
| 1 个 | 换行（同一段） |
| 2 个 | 空 1 行 |
| 3 个 | 空 2 行 |
| N 个 | 空 N−1 行，最多 10 行 |

### 行内空格

**字与字之间的空格也如实保留。**

| 写法 | 渲染结果 |
|---|---|
| `甲 乙` | `甲 乙`（1 个空格） |
| `甲   乙` | `甲   乙`（3 个空格保留） |

**唯一的例外是行首空格**——开头的空格不显示。

Markdown 里“几个空行都一样”、“连续空格会合并成一个”，mdh 都不是——**你留几个就是几个。**

## 三、块（mdh 的核心结构）

### 基本形状

```mdh
***table
head: 部门, 人数
- 技术部, 42
***table-end
```

**开始用 `***块名`，结束用 `***块名-end`。** 成对出现。

### 块可以带三种东西

| 形态 | 写法 | 例子 |
|---|---|---|
| 参数 | `***块名(参数)` | `***chart(bar)` |
| 引用名 | `***块名 ref="名"` | `***table ref="员工"` |
| 题注 | `***块名 caption="注"` | `***table caption="2024 数据"` |
| 组合 | `***块名(参数) ref="名" caption="注"` | `***chart(bar) ref="销量" caption="各月销量"` |

### 引号和参数的区别

| 参数类型 | 引号 | 例子 |
|---|---|---|
| 固定取值 | **不加** | `***chart(bar)`、`***column(1fr/1fr)` |
| 你自定义的名字 | **加双引号** | `***table ref="员工表"` |

### `ref=` 和 `caption=` 不是一回事

| | 给谁看 | 显示吗 | 用途 |
|---|---|---|---|
| `ref="员工表"` | **机器** | ❌ 不显示 | 让 `@员工表` 能引用到它 |
| `caption="各部门人数"` | **人** | ✅ 显示 | 表格上方的题注文字 |

**想让读者看见，用 `caption`。想让 `@` 引用得到，用 `ref`。**

`ref` 的字符限制：中文、字母、数字、`_`、`-`。**不能有空格**。

```text
***table ref="员工表"        ✅
***table ref="Sales 2024"    ⚠️ 有空格，@ 引用不了
```

|---|---|---|
| `***list` | 列表（可放非列表内容） | `***list` … `***list-end` |

## 五、表格

```mdh
***table caption="各部门人数"
head: 部门, 人数, 备注
- 技术部, 42, 含外包
- 市场部, 18, 全职
***table-end
```

| 要点 | 说明 |
|---|---|
| 表头 | `head:` 开头，逗号分隔 |
| 数据行 | `-` 开头，逗号分隔 |
| 单元格里有逗号 | 用反引号包住 `` `a,b` `` |
| 横向合并表头 | **相邻且文字完全相同的表头自动合并** |

## 六、分栏

```mdh
***column(1fr/1fr)
左边内容

@next-column

右边内容

***column-end
```

| 要点 | 说明 |
|---|---|
| 栏宽 | `1fr/2fr` 这样写，**最多 3 栏** |
| 切换下一栏 | `@next-column` 单独一行 |
| 每栏内 | 可以放任何块（表格、列表、代码…） |

## 七、`@` 家族

分两类：**行内用的**（写在句子中间）和**整行指令**（独占一行、无闭合）。

### 行内使用

| 写法 | 用途 |
|---|---|
| `@名字` | 引用一个块或标题（点击跳转） |
| `@foot(来源)` | 插入脚注上标 |
| `@foot(来源): 内容` | 定义脚注（通常放文末） |
| `@link(文字, "地址")` | 链接（**地址必须加引号**） |
| `@img(描述, "地址")` | 图片（**地址必须加引号**） |

**地址为什么要加引号**：地址里可能有逗号、括号。

```mdh
@link(维基, "https://en.wikipedia.org/wiki/Washington,_D.C.")
@img(图, "https://x.com/a.png?v=1&w=2")
```

不加引号的话，会**原样显示成文字**，不报错。

### 引用显示成什么样

`见 @员工表 可知` —— 目标存在时渲染成可点的**主题红文字**：

| 情况 | 显示 |
|---|---|
| **目标存在** | 主题红、可点跳转；**没有下划线**；悬停时颜色提亮一档 |
| **目标不存在** | 灰字 + 虚下划线；不可点 |

```
见 @员工表 可知     ← 员工表存在 → 红字，点了跳到那张表
见 @不存在 可知     ← 不存在    → 灰字虚线，点了没反应
```

**为什么正确引用不加下划线**：下文已经有大量真实链接（`@link`），
如果引用也带线，读者分不清哪些是外链、哪些是文内跳转。
红色本身就是「可以点」的信号，够了。

### 整行指令（独占一行，无闭合）

| 写法 | 用途 |
|---|---|
| `@toc` | 目录占位符 |
| `@page(slides)` | 整篇设为幻灯片模式 |
| `@next-slide` | slides 模式下切到下一页 |
| `@next-column` | `***column` 块内切到下一栏 |

> **`@page` 是整篇级**，写一次就管全文；`@next-slide` / `@next-column` 是
> 分隔符，N 页/栏只需 N−1 个。

### `@toc` 收哪些标题

**H1–H4 进目录，H5、H6 不进。**

| 标题 | 进目录 |
|---|---|
| `#` ~ `####`（H1–H4） | ✅ |
| `#####` / `######`（H5 / H6） | ❌ |

H5、H6 照常显示在正文里，只是不列进目录 —— 文档一旦写深，
目录会变成一张满屏的清单，反而失去导航作用。

缩进按层级递增：H1 顶格，H2 / H3 / H4 各多 0.9em。

## 八、元信息

放在文件最开头，整篇共用一个：

```mdh
===
title = 项目周报
author = 张三
===
```

| 字段 | 用途 |
|---|---|
| `title` | 文档标题（给程序读的，作为浏览器标签页标题） |
| 其它 | 你自己定义的键值，渲染时不显示 |

## 九、页面形态

```mdh
@page(slides)
# 第一页

@next-slide

# 第二页
```

| 取值 | 效果 |
|---|---|
| `slides` | 幻灯片模式，一页一屏 |
| 不写 | 普通网页（一条流） |

`@next-slide` 是切页，**N 页只需 N−1 个**。

## 十二、什么能套什么

| 外层 \ 内层 | table | list | math | mermaid | column | 代码块 | 引用 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| **table** | — | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |
| **list** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **column** | ✅ | ✅ | ✅ | ✅ | ❌ | ✅ | ✅ |
| **quote** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **裸列表** | ❌ | ✅ | ❌ | ❌ | ❌ | ✅ | ✅ |

**表格是最内层**，里面不能再放别的块。
**分栏不能嵌套分栏** —— 写了内层的 `***column`，它会被**静默丢弃**（内容不见了，也不报错）。

> 表里的 ✅ 都受**总嵌套深度 ≤ 3 层**约束。深度怎么数见下节。

### 层数怎么数

**从列表项算第一层，不是从 `***list` 算。**

`***list` 是声明型容器，本身不算一层——**第一层是它里面的 `- 项`**。

```
***list          ← 声明，不算层
- 项一            第 1 层  ← 从这里开始数
  ***column      第 2 层
    ***list      第 3 层  ← 到顶
      ***table   第 4 层  ← 超限，变成纯文字
```

三层是合法的；再往里放 `***table` 就是第 4 层，超限。

> `***list` 虽然不数层，但它**占一个 ID**。
> 占号决定它能不能被选中/引用，数层决定它内部能套几层——两件事不冲突。

### 超限了会怎样

**整块变成普通文字**：内容照常显示，只是不再是表格/列表，没有样式。

不报错、内容不丢——你能看出自己写深了，读者也读得到内容。

### list 里放块：顶格、缩进都可以

`***list` 里既能放**顶格**的块（与列表项平级），也能放**缩进**的块（成为某一项的子项）。

**顶格写 —— 块和列表项平级：**

```mdh
***list
- 项一

***table caption="表一"
head: a
- 1
***table-end

- 项二
***list-end
```

`***list` 是声明型：它自己占 `M1`，列表项和顶格块都是**平级内容**，依次拿 `M2`、`M3`、`M4`：

```
M1          列表
M2          项一
M3          表格        ← 顶格 → 与项平级
M3-N1       表格的行
M4          项二
```

**缩进写 —— 块成为这一项的子项：**

```mdh
***list
- 项一

  ***table caption="这一项的子表"
  head: a
  - 1
  ***table-end
***list-end
```

表格挂在「项一」下面，进它的下一层：

```
M1          列表
M2          项一
M2-N1       表格        ← 缩进 → 项一的子块
M2-N1-O1    表格的行
```

| 写法 | 结果 |
|---|---|
| 顶格 `***table` | 与列表项**平级**，插在项之间 |
| 缩进 `  ***table` | 成为**上一项的子项** |

> 缩进表达「归属」这条规则，只在 `***list` 块内生效。
> 块外的缩进（普通正文、table 块内）不承担语义。

## 十二·补、命名闭合

块可以用 `-名字` 后缀标注，让长文档里的开头和结尾对得上：

```mdh
***table-员工甲 ref="员工"
head: 姓名, 部门
- 张三, 技术部
***table-员工甲-end
```

| 写法 | 结果 |
|---|---|
| `***list-abc` … `***list-abc-end` | ✅ 正常 |
| `***list-abc` … `***list-xyz-end` | ❌ **报错**：名字对不上 |
| `***list-abc` … `***list-end` | ✅ 闭合不带名，宽松接受 |

**规则**：闭合标记写了名字就校验，没写就放行。

- `-名字` 是**位置标记**，语法层，闭合校验只认它
- `ref="名字"` 是**引用名**，内容层，只给 `@名字` 用 —— **和闭合无关**

```
***table ref="员工"           ← 只有引用名，闭合就写普通 ***table-end
head: a
- 1
***table-end                 ✅

***table-甲 ref="员工"        ← 各管各的：-甲 管闭合，员工 管引用
head: a
- 1
***table-甲-end               ✅
```

> 拿 `ref` 名去闭合（`***table-员工-end`）**不会**被当成闭合标记——
> `ref` 从来就不是块名。早先实现把两者混在一起，是个 bug，2026-11-25 已分开。

## 十三、几条容易踩的

| # | 注意 |
|---|---|
| 1 | **块必须闭合**。写了 `***table` 忘了 `***table-end`，后面的内容会被吞进去 |
| 2 | **符号只在行首生效**。`***`、`//`、`@page` 出现在行中间就只是文字 |
| 3 | **认不得的东西不报错**。写错块名不会崩，内容照常显示 |
| 4 | **缩进只在列表里表达层级**。别的地方缩进没有语义 |
| 5 | **反引号是唯一的转义**。想显示 `**` 本身，就用反引号包住 |

## 十四、保留关键字（语法已占用，当前不生效）

这些词**语法上已经保留**，将来会实现。现在写出来**原样显示，不报错**：

| 关键字 | 将来用途 |
|---|---|
| `@title(名字)` | 文档顶部大标题（不进目录） |
| `@tag(名字)` | 文档标签（可分类） |
| `@theme(名字)` | 套用母版主题 |
| `@slide-theme(页型)` | 标记幻灯片页型 |
| `@next-tab(标题)` | tabs 块内切页 |
| `***tabs` … `***tabs-end` | 切换式容器 |

**为什么要提前占位**：避免将来启用时，和你正文里已有的同名文字冲突。

### 显示成什么样

| 关键字 | 现在的显示 |
|---|---|
| `@` 开头的（含 `@title`） | 红字（`.mdh-keyword-reserved`），标出「这是语法词」 |
| `***tabs` … `***tabs-end` | 按未知块处理，内容照常显示 |

红字是**故意的**：让你一眼看出「这是个语法词，但现在还没生效」，
而不是让它混在正文里看不出来。将来实现后，红字就会变成真正的大标题 / 标签。

## 十五、实验品：`***chart`

```mdh
***chart(bar)
label, 销量
一月, 120
二月, 90
***chart-end
```

**现在能跑，但这是试验品——不算 1.0.0 的正式功能。**

| 项 | 状态 |
|---|---|
| 语法 | 块名 `chart`，参数 `bar` / `line` / `pie` |
| 能否渲染 | ✅ 能，产出图表 |
| 是否承诺稳定 | ❌ **不承诺**。行为、参数、视觉都可能改 |
| 是否必需 `chart.js` | 是，但**不参与启动自检**（见 README） |

**为什么不上正式名单**：它还没到「完全体」——参数、样式、导出都还没定。
放出来是因为已经能用，你自己玩玩没问题；但别写进正式文档。

> 反过来，等你哪天看到它进了「已知的块」，就是正式支持了。

## 十六、完整例子

```mdh
===
title = 项目周报
===

@toc

# 一、本周进展

完成了 **接口联调**，详见 @link(文档, "https://example.com/doc")。

- 完成登录
- 完成支付
  - 退款未测

***table caption="任务分配"
head: 事项, 负责人, 状态
- 接口联调, 张三, 已完成
- 支付接入, 李四, 进行中
***table-end

# 二、下周计划

***column(1fr/1fr)
### 技术
- 退款流程

@next-column

### 业务
- 客户回访

***column-end

---

*备注：数据截至周五。*
```
